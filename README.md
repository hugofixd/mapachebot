# Mapachebot avanzado

Discord.js v14 con SQLite, tickets persistentes, paneles con botones, control de acceso, claim, add/remove, lock/unlock, cierre, valoraciones, bienvenidas, boosts personalizables, embeds y moderación.

## Uso
`npm install`, copia `.env.example` a `.env`, configura `DISCORD_TOKEN` y `CLIENT_ID`, ejecuta `npm run deploy` y después `npm start`.

Comandos: `/ticket`, `/ticket-config`, `/rate`, `/welcome configurar`, `/boost configurar`, `/embed`, `/purge`, `/lock`, `/unlock`, `/warn`, `/warnings`, `/timeout`, `/kick`, `/ban`, `/serverinfo`, `/userinfo`.
